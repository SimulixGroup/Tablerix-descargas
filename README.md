# Tablerix · descargas

Instaladores oficiales de **Tablerix**, simulador educativo de tableros eléctricos y PLC según DS N°8 y pliegos RIC.

- Descarga la última versión en **[Releases](../../releases/latest)**.
- Para instalar y abrir Tablerix necesitas un código de activación y su clave de acceso.
- Tablerix se actualiza solo desde **Ayuda › Buscar actualizaciones**, y solo instala versiones firmadas por Tablerix.
